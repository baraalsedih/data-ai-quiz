# DataCamp — Data & AI Roles Quiz

A live, phone-friendly multiple-choice quiz for the Data & AI Roles session. Opens with a "which university are you from?" poll, then 10 scored questions.
Same architecture as the icebreaker app: one static page, public MQTT over WebSockets, no backend.

- **Attendees:** https://baraalsedih.github.io/data-ai-quiz/
- **Host dashboard:** append `#6q2haqrhfk` to the link above.

The host controls the flow (start → reveal → next). Answers lock in on tap,
one point per correct answer, with a live leaderboard on the host screen and
the final scores on everyone's phone.
